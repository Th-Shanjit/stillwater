# Stillwater V2 Production Components

## Visual direction

Retain Daylight and Midnight palettes.
Retain Newsreader and system sans-serif typography.
Prioritise practical actions above lengthy introductions.

## Components

StillwaterUI.tsx:
- V2Screen: responsive layout and status bar.
- V2Text: semantic typography.
- V2Button: accessible action hierarchy.
- V2Card: consistent surfaces.
- V2ActionRow: selectable practical actions.
- V2Artwork: water, threshold and growth motifs.

StillwaterBreathing.tsx:
- Optional three-cycle guided breathing practice.
- Four-second inhale and six-second exhale.
- Native-driver animation.
- System reduced-motion alternative.
- Pause when app backgrounds or screen loses focus.
- No claim of clinical effectiveness.

## Design principles

Primary action before supplementary content.
Use one recommendation with optional alternatives.
Prayer is available without becoming mandatory.
Avoid decorative artwork displacing important actions.
