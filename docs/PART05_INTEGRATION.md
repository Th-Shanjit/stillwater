# Part 05E - Sanctuary Integration

Daylight and Moonlight selection is persisted locally.

Existing sanctuary_state records receive a validated
appearance column without modifying the growth stage.

The Progress preview and dedicated Sanctuary read
the same saved appearance and permanent growth state.

Unresolved database reads show a neutral placeholder,
rather than presenting stage zero as the saved landscape.

Refresh failures retain previously loaded scenery
where available and offer a retry.

No view, prayer, appearance or visit tracking is added.

Growth thresholds remain internal.
No new dependencies or cloud services are introduced.
