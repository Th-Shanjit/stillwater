# Part 03A - Immediate Support

## Recovery flow

Practical environmental action comes first.

Optional support:
- Three-cycle breathing practice.
- Alternative practical actions.
- Existing personal if-then plans.
- Extended free guided practice.
- Trusted-contact message draft.
- Short optional prayer.

The user can leave without completing a practice.

No premium restrictions apply to this screen.

## Recorded outcomes

steady:
Explicit user report of feeling steadier.

ready_to_step_away:
User reports readiness to leave and try an action.
Not proof that an action was completed.

exited_early:
User closes the support experience.

Hardware back or process termination may exit without
creating an event. Missing events imply nothing.

Breathing count records completed cycles in the longest
single breathing sequence during the intervention,
up to three.

Audio usage records playback, not opening the player.

Existing database records remain unchanged.
No SQLite schema migration is required.

Logging is best-effort and does not block leaving.

## Trusted contact

Opens the device messaging composer with a neutral draft.
Does not send a message automatically.
No recovery history is included.
