# Parts 07A, 07B and 07C

## Shareable moments

The public website provides a complete manual quiet
moment with optional prayer and a text fallback.

It has no account, tracker, cookie, form, database
connection or personal recovery integration.

Hosting providers may retain ordinary access logs.

## Walk With Me

Recipients receive a public programme preview and
can explicitly enrol in the pinned edition inside
the installed application.

This is independent participation, not a linked
membership. No sender identity, acceptance tracking
or shared progress exists yet.

## Links

Public HTTPS links use a fragment containing
kind, content ID and version.

Native links use stillwater://shared with
equivalent validated parameters.

Invalid or unsupported invitations are rejected.

The custom scheme is not a verified universal link.
Android App Links and iOS Universal Links require
a deployed domain and platform association files.

First-time users may need to reopen an invitation
after completing onboarding.

## Deployment

Run node scripts/build-share-site.cjs from the root.

Deploy only web-share/site to an HTTPS static host.

Set EXPO_PUBLIC_STILLWATER_SHARE_URL to the actual
deployed address and restart or rebuild the app.

No fictional production URL is supplied.

Until configured, public sharing buttons are disabled.
