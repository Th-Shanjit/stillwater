# Part 05D - Permanent Sanctuary Growth

Growth uses lifetime distinct recorded practice dates.

Morning and evening practice on the same date count
as one practice day.

Returns alone, visits, breathing repeats, prayer views
and time spent in the application do not award growth.

Thresholds: 1, 5, 12 and 25 practice dates.

Additions: olive sapling, bench, lantern, wildflowers.

Thresholds are not displayed as goals or countdowns.

The sanctuary_state table stores one permanent stage.

An atomic MAX update prevents accidental regression.
Historical eligible practices count toward growth.

The state refreshes when Progress or Sanctuary gains
navigation focus. No background monitoring is required.

Daylight and moonlight share the same growth stage.

Ordinary setbacks and absences never remove additions.

The base environment remains available to everyone.
No premium restrictions are introduced.

Permanent means within retained local application data,
not across uninstall, data deletion or device loss.

A future full-data deletion workflow must remove this
table's personal state as well as the recovery records.

Artwork, pacing and growth thresholds remain subject
to accessibility, clinical and user review.

Native validation remains pending.
