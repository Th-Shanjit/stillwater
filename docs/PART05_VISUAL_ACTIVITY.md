# Part 05B - Visual Activity Summaries

The rolling 30-day calendar aligns to Monday-first
weeks and shows explicit date ranges.

Practice and return markers can coexist.

Morning and evening counts represent recorded days
with those practices, not total session counts.

No streaks, abstinence percentages or punitive colours.

Large-text users receive a readable calendar list
and horizontal Compass chart.

The Compass distribution is shown when observations
exist. Highlighted repeated patterns still require
the existing Phase 04 evidence thresholds.

No database or dependency changes.
No historical records are rewritten.

Calendar and chart rendering require native testing.
