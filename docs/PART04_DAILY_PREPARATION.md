# Part 04B - Adaptive Daily Preparation

## Recommendation priority

1. Existing active boundary remains visible.
2. Repeated recorded context.
3. Repeated recorded time window.
4. General preparation suggestion.

Personal Compass supplies evidence thresholds.

These are explainable suggestions, not predictions,
clinical assessments or guarantees of effectiveness.

## Content

Each suggestion has a stable ID, version, title,
practical plan, reason and visual icon.

The initial content set is deliberately limited.
Expand and review content during production.

## Persistence

No plan is saved automatically.

The user explicitly accepts a suggestion.
Existing boundaries are checked before insertion.

A chosen plan retains the existing 24-hour duration.

No additional personal data is stored by the engine.

## Reliability

If Compass cannot load, use a general suggestion.
Core support remains available independently.

Existing active plans take priority.
