# Part 02A and 02B: Live Shell and Today

The approved V2 component system is now used by the
live Today screen.

## Navigation

Today / Journey / Progress.

Existing route filenames remain unchanged.

Journey retains the previous Library features.
Progress retains plans, boundaries, trusted contact
and settings until those features receive dedicated screens.

## Today

Immediate support is the first prominent action.

Start Again launches the existing grace-reset workflow.
My Plan opens the existing planning tools.

A generic preparation suggestion can be explicitly saved
as a real local 24-hour boundary.

Morning content is optional and collapsed by default.
Evening Examen remains available.

## Progress

The recorded activity calendar has moved to Progress.
Both practice and return may appear on the same date.

No missing day is interpreted as abstinence.

## Transitional limitations

Today uses the approved Daylight design system.
Journey and Progress retain their existing screen styles
until their dedicated migration phases.

The current Pause and Grace Reset workflows are unchanged.
They will be rebuilt in Part 03.

Night intervention status bar styling is route-aware.
Full application-wide appearance preferences remain pending.

No recordings are required.
The development Design Lab entry is removed from Today,
but its component source is retained as a reference.
