# Parts 08D, 08E and 08F

## Creator submissions

The creator toolkit generates editable programme drafts
and structured editorial review records.

Draft generation does not register a publisher,
approve a programme or publish content.

Structural checks reuse the existing programme parser
and edition fingerprint registry.

Review records identify the exact content edition
and its SHA-256 fingerprint.

Human review is mandatory.

Review records are local working documents, not
cryptographically signed approvals.

After approval, use the manual registration procedure
documented in PART06_PROGRAMME_PUBLISHING.md.

Publisher profiles must also be curated separately.

## Promotional materials

The host-material generator produces standalone
printable HTML documents.

Public posters support the approved free general
programme Three Quiet Evenings version 1.

Poster generation requires a supplied HTTPS
public sharing address.

The address must be deployed and manually verified
before distributing the generated material.

Facilitator guides contain approved programme content,
session agendas and safeguarding guidance.

Generated documents contain no participant details.

## Host integration

Stillwater Host links to the existing invitation
and public sharing experience.

Connected Circles remain optional.

Hosting does not create personal participation
records or transmit recovery information.

## Commercial boundaries

Basic hosting remains free.

No creator payments, royalties, purchase flows
or paid host subscriptions are introduced.

Those require commercial agreements and the
monetisation work in Phase 09.

## Acceptance tests

- Create a valid creator draft.
- Edit and structurally validate a draft package.
- Generate a pending editorial review record.
- Reject modified registered editions.
- Generate printable promotional materials.
- Generate all three facilitator guides.
- Print or save materials using a browser.
- Open the sharing screen from Stillwater Host.
- Verify existing Circles and programme functionality.
- Confirm no private participant information is exported.

## Remaining work

External publisher onboarding.
Human content and safeguarding review.
Verified publisher identity.
Hosted creator submissions.
Public sharing website deployment.
QR-code generation.
Shared event scheduling.
Media production and licensing.
Native and multi-device validation.

No self-service publisher marketplace is implemented.
