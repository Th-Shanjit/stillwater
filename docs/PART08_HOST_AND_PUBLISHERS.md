# Parts 08A, 08B and 08C

## Publisher profiles

Publisher profiles are curated local metadata.

The initial profile represents Stillwater.

Programme attribution is matched against the
programme publisher ID, name and category.

This is not identity verification, licensing
verification or an external publisher account.

Publisher profiles list the latest available
programme editions without changing existing
participants' pinned enrolments.

## Stillwater Host

Basic hosting is free.

The initial host toolkit supports the three sessions
of Three Quiet Evenings version 1.

Each host guide includes preparation instructions,
welcome, settling, guided experience, optional
discussion and closing.

Suggested timings are advisory.

Hosts may skip, repeat or revisit agenda items.

The existing programme player is reused for group
guidance without participation persistence.

Host mode requires explicit acknowledgement
of confidentiality and safeguarding guidance.

## Privacy

No attendance is recorded.

No personal recovery records are accessed.

Hosting does not update programme participation,
the recovery calendar, Personal Compass or Sanctuary.

Circles remain optional and separate.

## Content governance

Only explicitly approved programme editions
can enter host mode.

Private recovery programmes are not automatically
eligible for group facilitation.

The initial pilot is intended for adult groups.

Professional safeguarding and content review
remain required before public distribution.

## Audio and artwork

Existing text and visual fallbacks are used.

Group practice and host introduction recordings
remain on the production audio backlog.

No additional recordings are commissioned here.

## Limitations

Host agenda position is temporary.

There are no persistent events, attendance lists,
shared schedules or host accounts.

Publisher profiles are local, not remotely editable.

Native rendering, back navigation and
accessibility remain to be tested.
