# Stillwater bundled audio

Place only approved final MP3 files in this directory.

Recognised filenames:

- urge_1am.mp3
- post_slip_fraud.mp3
- lonely_house.mp3
- eyes_closed_examen.mp3

Each recording requires a corresponding review JSON file.

Use the recording toolkit to create the review record
and synchronise the bundled recording registry.

Do not add unlicensed voice recordings or music.

The application remains functional without these files.
